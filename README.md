# 🎮 Task 1 — Tic-Tac-Mind

### AI-Powered Tic-Tac-Toe Game

Tic-Tac-Mind is an AI-powered implementation of the classic Tic-Tac-Toe game where a human player competes against an intelligent computer opponent.

The AI uses game-search techniques to evaluate possible moves and make optimal decisions.

### Key Features

- Human vs AI gameplay
- Intelligent AI opponent
- Minimax-based decision making
- Game-state evaluation
- Win, lose, and draw detection
- Interactive gameplay
- Responsive interface

### Technologies

- Minimax Algorithm

- Search Algorithms

### AI Concepts Demonstrated

# 🖼️ Task 2 — Visionary AI

### AI Image Caption Generator

Visionary AI is a full-stack AI application that analyzes uploaded images and generates meaningful caption variations based on their visual content.

The project combines a modern React frontend with a Python backend and AI vision capabilities to understand image content before generating captions.

### Key Features

- AI-powered image understanding
- Multiple caption variations
- Creative caption generation
- Modern interactive interface
- React + Vite frontend

# 🎬 Task 3 — CineMatch AI

### AI-Powered Hybrid Movie Recommendation System

CineMatch AI is a full-stack movie recommendation platform that recommends movies based on movie similarity and user preferences.

The recommendation engine uses machine learning techniques including **TF-IDF vectorization and cosine similarity**, combined with personalization signals to generate relevant recommendations.

### Key Features

- 🔎 Movie search
- 🎬 Movie details
- 🤖 AI-powered recommendations
- ⭐ Movie ratings
- ❤️ Favorites / Watchlist
- 🎯 Personalized recommendations
- 📊 Match scores
- 💡 Recommendation explanations
- 🎭 Genre-based preferences
- 📱 Responsive interface
- ⚡ FastAPI backend
- 🧠 Machine learning recommendation engine

```text
Movie Dataset
      ↓
Data Cleaning & Preprocessing
      ↓
Feature Extraction
      ↓
TF-IDF Vectorization
      ↓

      ↓
User Preferences
      ↓
Hybrid Recommendation Scoring
      ↓
Personalized Movie Recommendations
